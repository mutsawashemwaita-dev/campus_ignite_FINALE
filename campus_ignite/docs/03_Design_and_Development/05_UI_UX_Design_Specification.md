## 1. Design System & Brand Identity

Campus Ignite follows an authoritative, vibrant institutional aesthetic tailored for Christian campus student communities.

| Design Token | Value | Usage & Context |
| --- | --- | --- |
| --ci-primary | #1A3C6E (Deep Navy) | Brand authority, primary buttons, headers, sidebar |
| --ci-accent | #C8A951 (Warm Gold) | Accent badges, live embers, active tabs, stat highlights |
| --ci-light | #E8F0FB (Soft Blue) | Background tints, table hover rows, pill backgrounds |
| Typography | 'Inter', -apple-system, sans-serif | High-legibility modern digital typography |

## 2. Micro-Interactions & Tactile Feedback

Count-up numeric animations on dashboard cards on page load.

Tactile click ripple waves on all buttons and action cards.

Quick Command Palette (Ctrl+K or /) with keyboard arrow navigation.

Subtle hover elevation and icon micro-tilt across quick action cards.
