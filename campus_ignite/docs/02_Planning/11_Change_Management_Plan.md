## 1. Change Control Process

All changes to baseline requirements, data schemas, or production code follow a structured 5-step control cycle:

1. Change Request Submission (using standard CR Form).

2. Technical & Security Impact Assessment.

3. Review and Approval by Project Lead & Pastoral Sponsor.

4. Development & Automated Testing in local environment.

5. Deployment to Render production with verification.

## 2. Emergency Changes

Critical security patches or live bug fixes may be fast-tracked with retrospective change logging within 24 hours.
