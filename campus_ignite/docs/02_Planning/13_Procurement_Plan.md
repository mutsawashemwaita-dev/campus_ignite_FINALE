## 1. Procurement Strategy

The system relies entirely on enterprise open-source software and managed cloud platforms, avoiding proprietary vendor lock-in.

| Resource | Provider / Vendor | Contract / License Type | Procurement Method |
| --- | --- | --- | --- |
| Web Container Hosting | Render Cloud Services | Standard PaaS (Free Tier) | Online Self-Service |
| PostgreSQL Database | Neon Tech | Serverless PostgreSQL | Online Provisioning |
| Application Framework | Django Software Foundation | BSD 3-Clause Open Source | pip / PyPI |
| UI Framework | Bootstrap & FontAwesome | MIT / Free License | CDN Integration |

## 2. Supplier Management & SLAs

Cloud vendor uptime commitments: Render 99.95%, Neon 99.95%. Multi-region failover and local backup dumps maintained weekly.
