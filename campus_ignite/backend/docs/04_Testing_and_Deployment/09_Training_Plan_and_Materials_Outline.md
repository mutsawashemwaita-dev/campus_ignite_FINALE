## 1. Training Curriculum by Role

Module A (Administrators): User creation, role assignment, system settings, backup review.

Module B (Pastors): Consolidated report review, service logging, pastoral directories.

Module C (Cell Leaders): Creating meeting reports, managing cell rosters, birthday alerts.

Module D (Department Heads): Department events, member rosters, calendar scheduling.
